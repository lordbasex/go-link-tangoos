# Idiomas de la interfaz

La interfaz está en **español** (la fuente) y en **inglés**. Todo pasa por `@tango/client`:

```ts
import { t, tn, tr, getLang, setLang, locale } from "@tango/client";
```

| Función | Para qué |
|---|---|
| `t("Crear volumen")` | Un texto de la interfaz. El español es la clave; en inglés devuelve la traducción registrada (o el español si falta). |
| `t("Montado en /{name}.", { name: v.name })` | Con variables: `{nombre}` se reemplaza en los dos idiomas. Nunca concatenar frases: `t("Hay {n} discos", { n })`, no `"Hay " + n + " discos"`. |
| `tn(n, "un disco", "{n} discos")` | Singular o plural según `n`. |
| `tr(mensaje)` | Un texto que llegó del NAS (aviso, título o detalle de un job, `error.message` que no vino en un `RpcError`). Los `RpcError` ya se traducen solos al crearse. |
| `locale()` | `"es-AR"` o `"en-US"` para `Intl` y `toLocaleString`. Nunca escribir `"es-AR"` a mano. |
| `getLang()` / `setLang(l)` | Idioma actual; `setLang` lo guarda en el navegador y recarga. |

## Catálogos

- Cada paquete tiene `src/i18n.en.ts` con **todas** sus traducciones:

  ```ts
  import { registerEn } from "@tango/client";

  registerEn({
    "Crear volumen": "Create volume",
    "Montado en /{name}.": "Mounted at /{name}.",
  });
  ```

  y su `src/index.ts` lo importa en la **primera línea**: `import "./i18n.en";` (así está registrado antes de que
  se evalúe cualquier `t()` a nivel de módulo).
- Las claves son exactamente el texto que se pasa a `t()` (mismos espacios, signos y `{variables}`). Las variables se
  conservan en la traducción.
- Mensajes del NAS: `packages/client/src/i18n/server.en.ts` traduce cada texto de `server.es.json` (lo genera
  `go run ./scripts/i18n-extract`). Los formatos de Go (`%s`, `%d`, `%v`, `%q`, `%w`) se conservan en el mismo orden,
  o con posición explícita (`%[2]s`) si el inglés los necesita en otro orden. Un test exige que no falte ninguno.

## Estilo del inglés

- Inglés de EE. UU., en oraciones (sentence case: "Create volume", no "Create Volume"), tono directo y corto como el
  español original. "NAS", "volume", "storage pool" (grupo de almacenamiento), "share"/"shared folder" (carpeta
  compartida), "snapshot" (instantánea), "pool" para ZFS, "brick", "node", "passphrase" (frase), "USB key" (llave USB).
- Los nombres propios y técnicos no se traducen: TangoOS, Btrfs, ZFS, RAIDZ, SMB, NFS, iSCSI, LUN, GlusterFS, etc.
- No hay voseo en inglés: "Elegí un volumen" → "Choose a volume".

## Qué no se traduce

- Datos: nombres de volúmenes, carpetas, usuarios, rutas, IQN, huellas.
- Los textos de los tests unitarios (corren en español) y los registros técnicos (logs).
